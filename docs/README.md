| --- | --- | --- |
| 프로젝트 사용 시작 | [Foundesign DocC](../Sources/Foundesign/Foundesign.docc/GettingStarted.md) | import와 작은 사용 예제부터 읽기 |

| AI의 작업 경로 탐색 | [루트 AGENTS](../AGENTS.md), 디렉토리별 AGENTS | 변경 범위에서 필요한 가이드로 이동 |
