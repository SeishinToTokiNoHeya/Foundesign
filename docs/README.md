# 문서 안내

## 목적에 맞는 문서 찾기

| 목적 | 원본 위치 | 읽는 방법 |
| --- | --- | --- |
| Foundesign 시작하기 | [Foundesign DocC](../Sources/Foundesign/Foundesign.docc/GettingStarted.md) | import와 작은 사용 예제부터 읽기 |
| API의 동작과 사용 조건 | `Sources/`의 공개 선언 위 `///` | Xcode Quick Help 또는 생성된 DocC에서 확인 |
| 여러 API의 조합 | 각 모듈의 `.docc` | 사용 시나리오와 관련 심볼 따라가기 |
| 기여 규칙 | 이 디렉토리의 `guides/` | 작업에 필요한 가이드만 읽기 |
| AI로 Foundesign을 사용하는 앱 개발 | [Foundesign Skill](../skills/foundesign/SKILL.md) | 사용 중인 커밋 확인 후 필요한 원본 문서 읽기 |
| AI로 Foundesign 자체 수정 | [루트 AGENTS](../AGENTS.md), 디렉토리별 AGENTS | 변경 범위에서 필요한 가이드로 이동 |
