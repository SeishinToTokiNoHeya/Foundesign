# ``Foundesign``

SwiftUI 앱에서 디자인 토큰과 컴포넌트를 함께 사용하는 진입 모듈입니다.

## Overview

앱에는 `Foundesign` 라이브러리를 연결하고 `import Foundesign`을 사용합니다.
이 모듈은 `FoundesignFoundation`과 `FoundesignComponent`를 재수출합니다.
토큰과 테마의 API 문서는 FoundesignFoundation, 컴포넌트의 API 문서는
FoundesignComponent 문서에서 확인할 수 있습니다.

패키지의 최소 지원 버전은 iOS 17, macOS 14이며 Swift tools 6.4를 사용합니다.
