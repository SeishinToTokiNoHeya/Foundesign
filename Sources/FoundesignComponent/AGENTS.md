# Component 작업

범위: 이 디렉토리의 모든 컴포넌트, 플랫폼 어댑터, DocC.

- 먼저 [컴포넌트 개발 규칙](../../docs/guides/components.md)을 읽습니다.
- 변경할 기능의 소스·문서·예제는 [기능 색인](../../docs/ai/catalog.json)에서 찾습니다.
- 공개 API와 문서는 [DocC 규칙](../../docs/guides/documentation.md)을 따릅니다.
- UIKit/AppKit 변경은 두 플랫폼의 동작과 공통 상태 모델에 미치는 영향을 확인합니다.
- 사용 안내는 [FoundesignComponent DocC](FoundesignComponent.docc/FoundesignComponent.md)에 연결합니다.
- 완료 전 [예제 기준](../../docs/guides/examples.md)과 [검증](../../docs/guides/validation.md)을 적용합니다.
