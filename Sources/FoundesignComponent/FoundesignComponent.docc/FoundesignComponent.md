# ``FoundesignComponent``

Foundesign의 테마를 사용하는 SwiftUI 컴포넌트입니다.

## Overview

앱에서는 `import Foundesign`으로 사용할 수 있습니다.
컴포넌트는 환경의 테마와 설정을 읽으며, 선택값은 공개 API의 Binding으로 전달합니다.
타입과 initializer의 주석에서 입력 제약과 상태 변경 시점을 확인하세요.
