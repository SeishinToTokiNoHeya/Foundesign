# Foundation 작업

범위: 이 디렉토리의 토큰, 테마, SwiftUI 확장, DocC.

- 먼저 [아키텍처](../../docs/architecture.md)와 [Foundation 규칙](../../docs/guides/foundation.md)을 읽습니다.

- 이 모듈은 Component에 의존하지 않습니다. 공통 디자인 값을 정의하고 의미별 토큰으로 제공합니다.
- 토큰 변경 시 사용 컴포넌트와 `Example/Example/Pages/Foundation/`의 영향을 확인합니다.
- 문서 진입점: [FoundesignFoundation](FoundesignFoundation.docc/FoundesignFoundation.md).
- 완료 전 [예제 기준](../../docs/guides/examples.md)과 [검증](../../docs/guides/validation.md)을 적용합니다.
