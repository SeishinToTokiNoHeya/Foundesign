# ``FoundesignFoundation``

컴포넌트의 색상·타이포그래피·간격·모서리를 정의하는 디자인 토큰과 테마입니다.

## Overview

``FoundesignTheme``은 의미별 토큰을 하나로 묶습니다. SwiftUI 환경의 `theme`에 주입하면
하위 Foundesign 컴포넌트가 같은 디자인 값을 사용합니다.
원시 색상 단계는 ``ColorPalette``, 용도별 색상은 ``ColorToken``에서 확인합니다.
