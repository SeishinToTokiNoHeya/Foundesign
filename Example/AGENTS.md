# Example 작업

- [예제 개발 기준](../docs/guides/examples.md)을 읽고 적용합니다.
- 소비자와 같은 `import Foundesign` 및 공개 API로 사용법을 보여 줍니다.
- 새 페이지는 `Example/Pages/FoundationPages.swift`의 enum·title·destination에 등록합니다.
- 기존 페이지에 기능을 추가해도 됩니다. DatePicker는 현재 WheelPicker 페이지에서 보여 줍니다.
- 기능에 관련된 상태와 경계 조건을 직접 조작할 수 있게 하고, 내부 구현을 복제하지 않습니다.
- [기능 색인](../docs/ai/catalog.json)의 예제 경로와 [검증](../docs/guides/validation.md)을 함께 확인합니다.
